## QAM — Quadrature Amplitude Modulation

Modulation scheme that encodes data by varying both the amplitude and phase of a carrier wave. Used in cable TV, DSL, Wi-Fi (802.11), and LTE to achieve high spectral efficiency. Higher QAM orders (e.g. 256-QAM, 1024-QAM) transmit more bits per symbol but require better signal-to-noise ratio.

**Difficulty:** Intermediate
**Category:** Networking


---

## QBIT — Quantum Bit

Fundamental unit of quantum information, analogous to the classical bit. Unlike a bit (0 or 1), a qubit can exist in a superposition of states. Used in quantum computing hardware such as superconducting circuits, trapped ions, and photonic systems. Relevant to post-quantum cryptography research.

**Difficulty:** Advanced
**Category:** AI


---

## QCOW — QEMU Copy-On-Write

Disk image format used by QEMU and KVM virtualization. Supports sparse allocation, internal snapshots, encryption, and compression. The current version (qcow2) is the default format in most Linux virtualization stacks including Proxmox and libvirt.

**Difficulty:** Intermediate
**Category:** OS


---

## QDR — Quad Data Rate

High-speed InfiniBand link standard operating at 40 Gbit/s (4x10 Gbit/s). Used in HPC clusters and high-performance storage fabrics. Preceded by DDR (20 Gbit/s) and succeeded by FDR and EDR generations.

**Difficulty:** Advanced
**Category:** Hardware


---

## QDSL — Queued Domain Service Layer

Middleware abstraction layer that queues DNS-related service requests for asynchronous processing. Used in large-scale enterprise DNS management platforms to decouple service logic from resolver infrastructure.

**Difficulty:** Advanced
**Category:** Networking


---

## QEMU — Quick EMUlator

Open-source machine emulator and virtualizer. Can emulate a full system (CPU, memory, devices) or run as a KVM accelerator for near-native performance. Supports x86, ARM, MIPS, RISC-V, and many other architectures. Core component of Proxmox, oVirt, and libvirt stacks.

**Difficulty:** Intermediate
**Category:** OS


---

## QFMT — Queue Format

Internal data structure or protocol field that defines how items are serialized and ordered within a message queue. Relevant in AMQP brokers (RabbitMQ, ActiveMQ), JMS implementations, and kernel scheduling queues.

**Difficulty:** Intermediate
**Category:** Dev


---

## QKDN — Quantum Key Distribution Network

Infrastructure for distributing cryptographic keys using quantum mechanical properties (e.g. photon polarization). Exploits the no-cloning theorem to make eavesdropping detectable. Active deployment in national and metropolitan research networks.

**Difficulty:** Advanced
**Category:** Security


---

## QKMS — Quantum Key Management System

System responsible for storing, distributing, and lifecycle-managing keys generated by a QKD network. Interfaces between quantum hardware and classical cryptographic infrastructure, managing key freshness and fallback to classical exchange.

**Difficulty:** Advanced
**Category:** Security


---

## QLDB — Quantum Ledger Database

AWS managed ledger database service providing a cryptographically verifiable, append-only journal. Despite the name, it uses classical cryptography (SHA-256 hash chains), not quantum computing. Designed for audit trails and regulatory compliance.

**Difficulty:** Intermediate
**Category:** Database


---

## QLEN — Queue Length

Metric indicating the number of pending items in a processing queue at a given moment. Monitored in network interfaces (txqueuelen in Linux), OS schedulers, message brokers, and load balancers. High sustained queue length indicates a bottleneck.

**Difficulty:** Base
**Category:** Networking


---

## QLOG — Queue Log

Structured log format documenting queue state transitions, enqueue/dequeue events, and errors. Used for debugging message brokers, job schedulers, and I/O subsystems. QUIC protocol also defines a qlog format as a companion diagnostic standard.

**Difficulty:** Intermediate
**Category:** Dev


---

## QMAP — Queue Mapping

Configuration that associates network traffic flows to specific hardware or software queues. Used in multi-queue NICs, CPU affinity tuning (irqbalance, XPS, RPS), and QoS traffic shaping policies.

**Difficulty:** Intermediate
**Category:** Networking


---

## QMF — Query Management Facility

IBM mainframe tool for querying and reporting on DB2 databases. Provides SQL execution, result formatting, and report generation within the z/OS environment. Still active in large enterprise and banking mainframe installations.

**Difficulty:** Advanced
**Category:** Database


---

## QMGR — Queue Manager

Core component of a message queuing system (e.g. IBM MQ, RabbitMQ) responsible for routing, persisting, and delivering messages between producers and consumers. Manages queues, channels, subscriptions, and delivery guarantees.

**Difficulty:** Intermediate
**Category:** Dev


---

## QNAP — Quality Network Appliance Provider

Taiwanese vendor specializing in NAS devices, network switches, and storage appliances. QNAP systems run QTS or QuTS hero (ZFS-based) and are widely used in SMB and prosumer home lab environments.

**Difficulty:** Base
**Category:** Hardware


---

## QNET — Quantum Network

Generic term for a communication network that uses quantum mechanical phenomena (entanglement, superposition) for data transmission or key distribution. Still largely experimental; national projects exist in China, the EU (OpenQKD), and the USA.

**Difficulty:** Advanced
**Category:** Networking


---

## QNMS — Queue Network Management System

Platform that monitors and manages queuing infrastructure across distributed environments. Tracks queue depth, message latency, dead-letter rates, and consumer lag across brokers and regions.

**Difficulty:** Intermediate
**Category:** Networking


---

## QOS — Quality of Service

Set of mechanisms that prioritize network traffic to guarantee bandwidth, latency, jitter, and packet loss targets for critical flows. Implemented via DSCP marking, traffic shaping, policing, and queuing disciplines (FIFO, WFQ, CBQ).

**Difficulty:** Intermediate
**Category:** Networking


---

## QPID — Apache Qpid

Open-source AMQP message broker and client library project under the Apache Software Foundation. Provides Java and C++ broker implementations along with multi-language client libraries. Used as an alternative to RabbitMQ in AMQP-based architectures.

**Difficulty:** Intermediate
**Category:** Dev


---

## QPOL — Queue Policy

Rules governing queue behavior: maximum depth, overflow handling (drop-head, drop-tail, reject), message TTL, and dead-letter routing. Configured in AMQP brokers, Kubernetes resource quotas, and OS scheduler parameters.

**Difficulty:** Intermediate
**Category:** Dev


---

## QPSK — Quadrature Phase-Shift Keying

Modulation technique that encodes 2 bits per symbol using four phase states (0, 90, 180, 270 degrees). Used in satellite communications, cable modems, and as the baseline modulation for LTE/5G control channels. More robust to noise than higher-order QAM.

**Difficulty:** Intermediate
**Category:** Networking


---

## QPI — QuickPath Interconnect

Intel proprietary point-to-point CPU interconnect that replaced the Front Side Bus in Nehalem architecture (2008). Provides high-bandwidth, low-latency links between processors in multi-socket servers. Succeeded by UPI (Ultra Path Interconnect) from Skylake SP onward.

**Difficulty:** Advanced
**Category:** Hardware


---

## QPRT — Queue Priority

Attribute assigned to a queue or message that determines processing order relative to other queues. Implemented in OS schedulers, network QoS systems, and message brokers to ensure high-priority traffic is processed first.

**Difficulty:** Base
**Category:** Dev


---

## QRNG — Quantum Random Number Generator

Hardware device that produces true random numbers by measuring quantum physical processes (photon emission, vacuum fluctuations). Unlike PRNGs, the output is non-deterministic. Used in cryptographic key generation and security-sensitive applications.

**Difficulty:** Advanced
**Category:** Security


---

## QRES — Queue Reservation

Mechanism that pre-allocates queue capacity or processing slots for specific clients or traffic classes. Prevents starvation of low-priority flows and provides deterministic latency guarantees in real-time systems.

**Difficulty:** Intermediate
**Category:** Dev


---

## QSAM — Queued Sequential Access Method

IBM mainframe data access method that reads and writes sequential datasets using a buffer queue. Pre-fetches records into buffers while the program processes earlier ones, improving I/O throughput on tape and disk.

**Difficulty:** Advanced
**Category:** OS


---

## QSFP — Quad Small Form-factor Pluggable

Hot-pluggable transceiver module used in high-density networking equipment. Supports 40G (QSFP+), 100G (QSFP28), and 400G (QSFP-DD) Ethernet and InfiniBand. Common on top-of-rack switches and HPC interconnects.

**Difficulty:** Intermediate
**Category:** Hardware


---

## QSIG — Q Signaling

Signaling protocol defined by ECMA and ISO for inter-PBX communication over ISDN. Used in enterprise telephony to carry supplementary service information (call transfer, forwarding, caller identification) between private telephone networks.

**Difficulty:** Advanced
**Category:** Protocol


---

## QSPI — Quad Serial Peripheral Interface

Extended version of SPI that uses four data lines (IO0-IO3) instead of one, quadrupling throughput. Widely used for flash memory (NOR flash) on embedded systems, microcontrollers, and SoCs. Common in BIOS/UEFI chip interfaces.

**Difficulty:** Intermediate
**Category:** Hardware


---

## QSTR — Queue Stream

Abstraction that presents a message queue as a continuous, ordered data stream. Used in event-driven architectures (Kafka Streams, NATS JetStream) where consumers process messages sequentially with replay capability.

**Difficulty:** Intermediate
**Category:** Dev


---

## QTAM — Queued Telecommunications Access Method

IBM access method for handling asynchronous terminal I/O on mainframes. Manages buffering and queuing of data between application programs and telecommunications lines. Predecessor to VTAM in SNA architectures.

**Difficulty:** Advanced
**Category:** Protocol


---

## QUIC — Quick UDP Internet Connections

Transport layer protocol standardized as RFC 9000. Built on UDP, it integrates TLS 1.3, eliminates head-of-line blocking, supports 0-RTT reconnection, and enables connection migration across IP changes. Foundation of HTTP/3.

**Difficulty:** Advanced
**Category:** Protocol


---

## QVGA — Quarter Video Graphics Array

Display resolution of 320x240 pixels, one quarter of VGA (640x480). Common in embedded systems, feature phones, small LCDs, and IoT displays. Requires minimal framebuffer memory, making it suitable for resource-constrained microcontrollers.

**Difficulty:** Base
**Category:** Hardware


---

## QVPN — Quantum-secured Virtual Private Network

VPN implementation that uses QKD-derived keys for key exchange instead of classical asymmetric cryptography. Provides forward secrecy resilient to quantum computing attacks. Commercially available from vendors like ID Quantique and Toshiba.

**Difficulty:** Advanced
**Category:** Security


---

## QWAN — Quantum Wide Area Network

Research-stage WAN architecture that uses quantum repeaters and entanglement swapping to extend QKD beyond the distance limits of direct fiber (typically 100-200 km). Under development in academic and national infrastructure projects.

**Difficulty:** Advanced
**Category:** Networking


---

## QDEV — Quantum Device

Physical implementation of a quantum computing element, such as a superconducting qubit chip, trapped-ion module, or photonic waveguide. Managed through control electronics and cryogenic systems in quantum computing platforms.

**Difficulty:** Advanced
**Category:** Hardware


---

## QGPU — Quantum GPU

Emerging co-processor category applying quantum acceleration to tasks typically handled by GPUs, such as optimization, sampling, and matrix operations. Current quantum accelerators (D-Wave, IBM Quantum) are specialized hardware, not direct GPU replacements.

**Difficulty:** Advanced
**Category:** Hardware


---

## QLAN — Quantum Local Area Network

Local network segment that distributes quantum keys or quantum states between nearby nodes using fiber or free-space optical links. Used in research labs and pilot deployments to test quantum communication protocols at short range.

**Difficulty:** Advanced
**Category:** Networking


---

## QPTP — Quantum Point-to-Point

Direct quantum communication link between two nodes using QKD over a dedicated fiber or free-space channel. The simplest QKD topology, limited by fiber attenuation to roughly 100-200 km without quantum repeaters.

**Difficulty:** Advanced
**Category:** Networking

## QUERY — Database Query Statement

Request for data retrieval or manipulation submitted to a DBMS. SQL queries use SELECT, INSERT, UPDATE, DELETE, and DDL statements. The query planner selects execution plans based on statistics, indexes, and join order. EXPLAIN/EXPLAIN ANALYZE shows the chosen plan and actual cost. Query optimization is the primary lever for database performance tuning.

**Difficulty:** Base
**Category:** Database


---

## QUEUE — First-In First-Out Data Structure

Abstract data structure where elements are inserted at the tail and removed from the head (FIFO semantics). Implemented as linked lists, ring buffers, or lock-free structures depending on concurrency requirements. Kernel message queues (POSIX mq_open), task queues in thread pools, network packet queues (qdisc in Linux), and job queues in distributed systems all implement queue semantics.

**Difficulty:** Base
**Category:** Dev

---

## QUART — Async Python Web Framework

Python async web microframework compatible with Flask's API but built on asyncio. Allows existing Flask applications to be ported to async with minimal code changes. Supports async request handlers, websockets, and server-sent events. Uses Hypercorn as its default ASGI server. Useful as a migration path from Flask to fully async architectures.

**Difficulty:** Intermediate
**Category:** Dev

---

## QDISC — Queuing Discipline

Linux kernel component of the traffic control (tc) subsystem that manages packet scheduling on a network interface. Different qdiscs implement different scheduling algorithms: pfifo_fast (default, three priority bands), HTB (Hierarchical Token Bucket for bandwidth shaping), FQ_CODEL (Fair Queue CoDel for bufferbloat), CAKE (Common Applications Kept Enhanced). Configured via tc qdisc commands.

**Difficulty:** Advanced
**Category:** Networking
