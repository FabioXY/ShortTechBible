## ORM — Object-Relational Mapper

A programming technique and library that converts between incompatible type systems (object-oriented language types and relational database tables) automatically. An ORM lets developers interact with a database using language objects and methods instead of raw SQL. Examples: SQLAlchemy (Python), Hibernate (Java), Entity Framework (.NET). ORMs trade raw query control for developer productivity.

**Difficulty:** Intermediate
**Category:** Database

## OSI — Open Systems Interconnection (model)

A conceptual framework (ISO/IEC 7498-1) that divides network communication into 7 ordered layers: Physical, Data Link, Network, Transport, Session, Presentation, Application. Each layer provides services to the one above and consumes services from the one below. The OSI model is primarily a teaching and troubleshooting reference; real protocols (TCP/IP) don't map to it cleanly.

**Difficulty:** Base
**Category:** Networking

## OTP — One-Time Password

A password that is valid for only a single authentication session or transaction, generated by a shared secret and a counter or timestamp. TOTP (time-based) uses the current Unix time; HOTP (HMAC-based) uses an incrementing counter. OTPs protect against replay attacks since each code expires immediately after use or after a short time window.

**Difficulty:** Intermediate
**Category:** Security

## OIDC — OpenID Connect

An identity layer built on top of OAuth 2.0 (RFC 8414) that adds authentication to OAuth's authorization framework. OIDC introduces the ID Token (a JWT containing user identity claims), a UserInfo endpoint, and a standardized discovery mechanism. It is the dominant SSO protocol for web and mobile applications, used by Google, Microsoft, and most identity providers.

**Difficulty:** Advanced
**Category:** Security

## OSPF — Open Shortest Path First

A link-state routing protocol (RFC 2328 for OSPFv2, RFC 5340 for OSPFv3) that builds a complete map of the network topology using LSA (Link State Advertisements) flooded to all routers in an area. Each router independently runs Dijkstra's SPF algorithm to compute the shortest path tree. OSPF supports VLSM, fast convergence, and hierarchical design via areas.

**Difficulty:** Advanced
**Category:** Networking

---

## OVF — Open Virtualization Format

An open standard (DMTF OVF Spec) for packaging and distributing virtual machines and appliances in a vendor-neutral format. An OVF package contains a descriptor XML file, optional disk images (VMDK or VHD), and a manifest. The single-file variant (.ova) is a TAR archive of all components. Supported by VMware, VirtualBox, Proxmox, and most hypervisors.

**Difficulty:** Intermediate
**Category:** Cloud
