## YAML — YAML Ain't Markup Language

A human-readable data serialization format designed for configuration files and data exchange. YAML uses indentation (spaces only, never tabs) to represent hierarchy and supports scalars, sequences (lists), and mappings (key-value pairs). It is a superset of JSON. Widely used in CI/CD pipelines (GitHub Actions, GitLab CI), Kubernetes manifests, Ansible playbooks, and Docker Compose.

**Difficulty:** Base
**Category:** Dev

## YUM — Yellowdog Updater Modified

A package manager for RPM-based Linux distributions (RHEL, CentOS, Fedora). YUM resolves dependencies automatically, manages repositories, and handles package installation, updates, and removal. It was replaced by DNF (Dandified YUM) in Fedora 22 and RHEL 8, which uses the same command syntax but has better dependency resolution and performance via the libsolv library.

**Difficulty:** Base
**Category:** OS

## YML — YAML (file extension)

The file extension used for YAML files. While .yaml is the officially correct extension per the YAML specification, .yml is the de facto standard due to older systems' 3-character extension limits and convention in tools like Docker (docker-compose.yml), Kubernetes, and GitHub Actions. Both extensions are functionally identical; .yml dominates in DevOps tooling.

**Difficulty:** Base
**Category:** Dev

## YARN — Yet Another Resource Negotiator

A cluster resource management and job scheduling framework introduced in Hadoop 2.0, separating resource management from the MapReduce programming model. YARN allows multiple processing frameworks (MapReduce, Spark, Tez) to share the same Hadoop cluster by negotiating resource containers. Each application has an Application Master that negotiates resources from the Resource Manager.

**Difficulty:** Advanced
**Category:** Cloud

## YARA — Yet Another Ridiculous Acronym

A pattern-matching tool and rule language used in malware research and threat detection. YARA rules define conditions based on strings (byte sequences, text, regular expressions) and boolean logic to classify and identify files or processes. Used by antivirus engines, SIEM systems, and incident responders to detect malware families, indicators of compromise (IOCs), and suspicious files at scale.

**Difficulty:** Advanced
**Category:** Security
