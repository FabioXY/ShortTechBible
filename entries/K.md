## KDC — Key Distribution Center

A trusted third party in Kerberos authentication that issues tickets granting access to services. The KDC has two components: the Authentication Server (AS), which validates credentials and issues a Ticket Granting Ticket (TGT), and the Ticket Granting Server (TGS), which exchanges the TGT for service-specific tickets. The KDC holds the master key database.

**Difficulty:** Advanced
**Category:** Security

## KVM — Kernel-based Virtual Machine

A virtualization module built into the Linux kernel (since 2.6.20) that turns Linux into a Type-1 hypervisor by leveraging CPU hardware virtualization extensions (Intel VT-x, AMD-V). KVM exposes each VM as a process; QEMU provides device emulation. KVM is the foundation of OpenStack, oVirt, Proxmox, and most Linux cloud infrastructure.

**Difficulty:** Intermediate
**Category:** OS

## KMIP — Key Management Interoperability Protocol

An OASIS standard protocol for communication between key management servers and clients. KMIP defines operations (Create, Get, Destroy, Register, Locate) for managing cryptographic keys, certificates, and secrets in a vendor-neutral way. Used in enterprise environments where multiple applications need to retrieve encryption keys from a centralized hardware security module (HSM).

**Difficulty:** Advanced
**Category:** Security

## KPI — Key Performance Indicator

A quantifiable metric used to evaluate success against a defined objective. In IT and DevOps contexts, KPIs include uptime percentage, mean time to recovery (MTTR), deployment frequency, error rate, and p99 latency. KPIs are only meaningful when paired with a baseline, a target, and a measurement interval — without these, they are vanity metrics.

**Difficulty:** Base
**Category:** Dev

## KNX — Konnex

A standardized network communications protocol for intelligent building automation: lighting, HVAC, blinds, security, and energy management. KNX devices communicate over twisted-pair wiring, RF, or IP. It is the most widely deployed building automation standard in Europe and is governed by the KNX Association and recognized by ISO/IEC 14543.

**Difficulty:** Advanced
**Category:** Networking
